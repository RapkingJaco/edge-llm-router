# 核心觀念

> 本專案跨 Phase 的關鍵觀念，白話 + 記憶鉤。隨開發補充。

## 權重條件化（goal-conditioned / 多目標 RL）
把「你多在乎延遲 vs 成本」的權重 `w` 當**環境狀態**餵給 agent，訓練時每局隨機換 w，
學成**一整族** `π(a|s,w)`。改 w 行為就變 → LLM 改 w 可**零重訓**切換行為。
一句話：**把偏好當輸入，一網打盡整條偏好光譜**。

## 負載相依延遲（排隊）
節點「忙→變慢」是問題的靈魂。延遲固定的話最佳解永遠是「全丟最快的」，RL 無事可學。

## Sim-to-Real
在**校準過的模擬**裡訓練（真硬體跑不了幾百萬步），再確保模擬夠像真實。
Domain Randomization 讓 agent 在「一整片可能的真實」裡訓練，真機值落在見過的範圍內就不水土不服。

## 結構化輸出（控制層）
事先給 LLM 一個 JSON schema，**逼它只能填格子**，回來保證可 parse。控制層「吐意圖」再由程式
換算成權重，比讓 LLM 直接吐數字穩。
